# Homologador SOAT - CUPS

[![Python](https://img.shields.io/badge/Python-3.x-blue.svg)](https://www.python.org/)
[![PyQt6](https://img.shields.io/badge/PyQt6-6.x-brightgreen.svg)](https://www.riverbankcomputing.com/software/pyqt/)
[![Pandas](https://img.shields.io/badge/Pandas-1.x-orange.svg)](https://pandas.pydata.org/)

**Aplicación de escritorio en Python con PyQt6 para la búsqueda y homologación eficiente de códigos SOAT y CUPS en el sector salud.** Permite buscar por código o nombre, facilitando el acceso rápido a la información necesaria.

**Demuestra habilidades en:**

* Desarrollo de interfaces gráficas con PyQt6.
* Manejo y procesamiento de datos con Pandas.
* Implementación de lógica de búsqueda eficiente.
* Creación de aplicaciones de escritorio funcionales.
